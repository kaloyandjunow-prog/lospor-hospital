LOSPOR Hospital - Windows kit / Комплект за Windows

1. Extract this zip on the Windows Server (or Windows 10/11) that runs Hyper-V.
   For a hospital without internet, extract it into the folder with the release files from the USB stick.
2. Double-click "Install LOSPOR Hospital" and answer the questions.
3. Keep the window open. It ends with the Go-live address.

1. Разархивирайте този zip на Windows Server (или Windows 10/11) с Hyper-V.
   За болница без интернет го разархивирайте в папката с файловете на изданието от USB паметта.
2. Щракнете два пъти върху "Install LOSPOR Hospital" и отговорете на въпросите.
3. Оставете прозореца отворен. Той завършва с адреса на страницата Готовност.

Documentation / Документация: docs/host-preparation.md in the release, https://lospor.org
